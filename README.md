### 🐸 Site pro Trabalho Sei Lá Man

Um site estático minimalista com temática escura, desenvolvido como parte do **Trabalho de Versionamento**. Possui navegação interna, um botão com poder de destruição em massa e, claro, um sapo redondo.

### ✨ Funcionalidades Principais

* **Botão Ez:** Um botão interativo com animação de escala (transform: scale(1.05)) ao passar o mouse.
* **Galeria do Sapo:** Exibição de imagem tratada via CSS para formato perfeitamente circular com borda temática.
* **Menu de Navegação:** Âncoras internas para rolar a página suavemente até o conteúdo desejado.
* **Design Customizado:** Interface moderna inspirada em modo escuro (#121214) com detalhes roxos e verdes.
